# Asset review before SignPath application

The original Wardogs screenshot is not included in this repository or in the application package.

`assets/role-icons.mjs` contains five manually drawn SVGs based on the class shapes in a screenshot supplied by the maintainer: Infanterie, Medic, Pilote, Builders and Driver. Launcher is an UMBRA-created rocket-launcher silhouette. Recon, Sniper and Libre use Lucide geometry under the included license.

The maintainer states that the redraws may be used, but has not supplied a third-party open-source license or a written permission document. **This file does not certify that reference-inspired artwork is covered by an OSI license.** Redrawing alone does not establish the scope of third-party rights.

Keep this issue explicit in the SignPath application. Before asserting full open-source eligibility, either document suitable rights for those five SVGs or replace them with clearly licensed alternatives. The candidate retains the requested appearance for review; no change is made to production.

Inter, Lucide, the UMBRA-owned logo/tones, vendored JS and corresponding native sources are listed separately in THIRD_PARTY.md. An eventual blanket MIT claim must not override third-party licenses or unresolved artwork rights.

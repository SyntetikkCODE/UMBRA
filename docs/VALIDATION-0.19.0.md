# Validation HEXAGONE 0.19.0

23 novembre 2026. Overlay vocal minimal et amplification de la sortie jusqu’à 300 %.

- 131 tests unitaires/API : positions dans les quatre coins, coordonnées de moniteurs négatives, paramètres invalides, limites des données, avatars raster locaux, sélection des joueurs et activité des seuls canaux écoutés, amplification et conservation du comportement à 100 %.
- Deux clients Electron avec API et LiveKit locaux, profils séparés, piste audio de test calme et traitement Studio pour mesurer cette piste sans suppression de bruit. Les fixtures restent hors production. Les fenêtres principales et les overlays sont vérifiés sur l’écran droit, sans simulation de touche globale ni interruption du jeu de l’utilisateur.
- L’overlay conserve les joueurs silencieux du salon ; les noms et anneaux s’allument lors d’une transmission réelle. Les profils sont envoyés séparément de l’activité pour éviter de retransmettre les photos à chaque prise de parole. Les photos acceptées sont uniquement des données PNG/JPEG/WebP bornées, jamais une URL distante.
- Fenêtre transparente, sans fond ni cadre : nom du salon, joueurs en dessous, photo et anneau. Fenêtre indépendante, non focalisable, au premier plan ; configuration native pour laisser passer les clics et masquer la fenêtre de la barre des tâches. Le test vérifie les positions, le focus, la transparence du rendu, la conservation à la réduction de la fenêtre principale et le masquage à la déconnexion. Les clics natifs de l’utilisateur ne sont pas simulés.
- Mesure du son effectivement reçu entre les deux clients : environ 3× d’amplitude à 300 %, avec `HTMLMediaElement.volume` limité à 1 et l’amplification supplémentaire appliquée par Web Audio. Le passage à 300 % est enregistré sans remettre la page en haut. Le casque coupé rend la sortie muette. Le retour micro et les notifications à 300 % sont testés sans diffuser les signaux de mesure dans les haut-parleurs du PC.
- Les tests de connexion et d’erreurs de périphériques de 0.18.1 sont conservés. Les profils existants gardent leur volume initial ; l’overlay est désactivé par défaut et sa configuration se conserve localement dans `voice-overlay.json`.
- Les scénarios overlay/amplification et connexion sont aussi réussis avec `dist/win-unpacked/HEXAGONE.exe` de la version finale. Mesure de l’exécutable : 3,02× dans le scénario testé. Les 110 fichiers embarqués contrôlés correspondent aux sources ; installeur et manifeste signé vérifiés, y compris par le vérificateur extrait de la version 0.17.0. Le site présente les 30 fiches de version et le lien du nouvel installeur, sans débordement aux largeurs mobiles testées.

Le jeu doit utiliser une fenêtre ou le plein écran fenêtré. Cet overlay repose sur une fenêtre Windows au premier plan, sans injection dans le jeu. Le plein écran exclusif n’est pas pris en charge. Aucun test en match Wardogs ni test de charge avec 40 clients simultanés n’est revendiqué.

Publication client uniquement : API 0.17.0, LiveKit, données et permissions serveur inchangés. Les choix audio sont enregistrés localement ; le volume 300 % ne nécessite pas de mettre à jour le serveur. Les manifestes signés et les installeurs doivent rester servis directement sur les deux sous-domaines de téléchargement.
